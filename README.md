# Leon Template

A clean and responsive landing page built with HTML5 and CSS3.

## Preview

A modern landing page featuring a clean layout, responsive design, and multiple sections for presenting services, projects, and information.

## Features

- Fully responsive design
- Clean and modern UI
- Responsive navigation menu
- Landing section
- Features section
- Services section
- Portfolio section
- About section
- Responsive layouts for different screen sizes
- CSS Grid and Flexbox layouts
- CSS variables and reusable styles

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Variables
- Font Awesome
